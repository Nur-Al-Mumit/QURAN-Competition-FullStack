## Implementation Plan: Final Attendance View Page

### Overview
Create `/admin/final-attendance-view` — a read-only, professional, compact view showing all users' final attendance and confirmation status, grouped by criteria (Al-Mahir / Al-Mubtadi), filterable by season, with search. Accessible to SUPER_ADMIN, ADMIN, VOLUNTEER.

---

### Step 1: Backend — New API Endpoint

**Add method to `VolunteerController`:**

`GET /admin/final-attendance-view?season_id=X` → `finalAttendanceView(Request $request)`

Logic:
- Accept optional `season_id` filter. If no season_id, fetch all seasons.
- Query `users_final_attendances` joined with:
  - `user_competition_forms` → `name_en`, `name_bn`, `reg_no`, `phone`
  - `criteria` → `name_en` (Al-Mahir / Al-Mubtadi)
  - `seasons` → `name`, `year`
- Left-join `user_final_confirmations` on `(user_id, season_id)` to get `status`, `has_consideration`
- Filter by season_id if provided
- Return flat array of rows + list of all seasons (for the filter dropdown)

Each row shape:
```json
{
  "user_id": 247,
  "name_en": "Ahmed",
  "name_bn": "আহমেদ",
  "reg_no": "RC2247693",
  "phone": "01712345678",
  "season_id": 2,
  "season_name": "2026",
  "criteria_id": 1,
  "criteria_name": "Al-Mahir",
  "attendance_status": 1,
  "confirmation_status": 1,
  "has_consideration": "family problem"
}
```

**Create route file:** `backend/routes/api/admin/final-attendance-view.php`
- `GET /admin/final-attendance-view` → `VolunteerController@finalAttendanceView`

**Edit:** `backend/routes/api/admin/api.php` — include the new route file

### Step 2: Frontend — Vue Page

**Create:** `frontend/pages/admin/(ADMIN)/final-attendance-view.vue`

UI Structure:
- **Header bar** with title "Final Attendance View" + Season dropdown + Search input (by name/reg no)
- **Two sections** (grouped by criteria):
  - **Al-Mahir (الماهر) — Expert** — table of criteria 1 users
  - **Al-Mubtadi (المبتدئ) — Beginner** — table of criteria 2 users
- Each table columns: `#`, `Name` (with reg no subtitle), `Reg No`, `Phone`, `Season`, `Confirmation` (badge), `Attendance` (badge), `Consideration`
- Badges:
  - Confirmation: green pill "Confirmed" / red pill "Not Confirmed" / gray pill "Pending"
  - Attendance: green "Present" / red "Absent" / amber "Late"
  - Consideration: shown as truncated text with tooltip
- Section headers show count `(12)` like final-confirmation.vue
- **Summary stats** at top: Total Confirmed, Total Present, Total count per criteria
- Print support like training-attendance-view.vue
