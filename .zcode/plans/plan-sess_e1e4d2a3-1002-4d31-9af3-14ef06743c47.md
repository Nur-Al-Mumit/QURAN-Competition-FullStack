# Training Dates + Dynamic Attendance Sheet + Attendance View

Makes `x.vue` dynamic (real roster + DB-backed training dates instead of hardcoded arrays) and adds the surrounding system: a per-season training-dates config table (handling off-days like 24 July within 22–27 July), a CRUD admin page for those dates, and a read-only recorded-attendance view table.

All backend mirrors existing `DashboardSettingController` / `TrainingIdCardController` conventions; frontend mirrors `training-id-card.vue` + `x.vue`.

## Part A — Backend: `season_training_dates` table + model

### A1. Migration (new)
**File (new):** `backend/database/migrations/2026_07_22_100000_create_season_training_dates_table.php`

Table `season_training_dates`:
- `id`
- `season_id` foreignId → `seasons`, `onDelete('cascade')` (dates belong to a season; deleting a season removes its dates)
- `date` date (one explicit date per row — NOT a range, so off-days/holidays inside a period are first-class)
- `is_off_day` boolean default false (true = holiday/off, e.g. 24 July; the sheet shows the column greyed/labelled "OFF" and it's excluded from attendance expectations)
- `note` string nullable (e.g. "Weekly holiday")
- `sort_order` integer default 0
- `timestamps`
- **unique(`season_id`, `date`)** — no duplicate date per season

Mirrors `progress_stages` migration style (explicit columns, `sort_order`, timestamps).

### A2. Model (new)
**File (new):** `backend/app/Models/SeasonTrainingDate.php`
- `$table = 'season_training_dates'`
- `$fillable = ['season_id', 'date', 'is_off_day', 'note', 'sort_order']`
- `$casts = ['date' => 'date', 'is_off_day' => 'boolean']`
- `season()` → belongsTo `Season`

## Part B — Backend: controller + routes (full CRUD + read endpoints)

### B1. Controller (new)
**File (new):** `backend/app/Http/Controllers/Api/V1/Admin/SeasonTrainingDateController.php`

Mirrors `DashboardSettingController` shape:
- `index(Request)` — validates nullable `season_id` (defaults to active season), returns `SeasonTrainingDate::where('season_id', ...)->orderBy('date')->get()` as `{ season_id, training_dates }`.
- `store(Request)` — validates `season_id|required|exists:seasons,id`, `date|required|date`, `is_off_day|nullable|boolean`, `note|nullable|string`, `sort_order|nullable|integer`; creates; returns `{ training_date }` with HTTP 201. (unique(season,date) DB constraint catches dupes.)
- `update(Request, SeasonTrainingDate $trainingDate)` — re-validate + `$trainingDate->update(...)`; return `{ training_date }`.
- `destroy(SeasonTrainingDate $trainingDate)` — delete; return `{ message: 'Deleted' }`.

Also two **read** endpoints for the sheet + view (mirror `TrainingIdCardController`):
- `seasons()` — `{ seasons, active_season_id }` (identical to the pattern used elsewhere).
- `sheet(Request)` — validates nullable `season_id`; returns `{ season_id, students, training_dates }` where:
  - `students` = the Mubtadi training-pass roster (same query as `TrainingIdCardController::data`: `UserPreliminaryResult` where `criteria_id=2` AND `result_category_id=2`, eager-loaded form+allocation, mapped to `{ reg_no, name_en, name_bn, phone, group, serial }`, sorted by serial).
  - `training_dates` = `SeasonTrainingDate::where('season_id', ...)->orderBy('date')->get(['id','date','is_off_day','note'])`.
- `attendanceView(Request)` — validates nullable `season_id`; returns `{ season_id, students, training_dates, attendance }` where:
  - `students` + `training_dates` same as `sheet()`.
  - `attendance` = a map keyed by `user_id` → `{ [date]: status }` from `UserTrainingAttendance` for that season's users+dates (one query, `whereIn` on the season's date list, grouped in PHP). Drives the recorded-attendance view table.

### B2. Routes (new)
**File (new):** `backend/routes/api/admin/season-training-dates.php`
```php
Route::controller(SeasonTrainingDateController::class)->prefix('training-dates')->group(function () {
    Route::get('seasons', 'seasons');
    Route::get('index', 'index');          // CRUD list
    Route::post('store', 'store');
    Route::put('{training_date}', 'update');
    Route::delete('{training_date}', 'destroy');
    Route::get('sheet', 'sheet');          // printable sheet data
    Route::get('attendance-view', 'attendanceView'); // recorded attendance
});
```
**Wire into loader:** add `include __DIR__ . '/season-training-dates.php';` to `backend/routes/api/admin/api.php`. Resolves to `/admin/training-dates/*`.
